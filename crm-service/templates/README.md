# قالب‌های اکسل ورودی

دو فایل برای بارگذاری گروهی. ردیف اول = عنوان ستون‌ها (فارسی). پارسر بر اساس
**نام ستون** می‌خواند، پس ترتیب ستون‌ها مهم نیست ولی نامشان باید دقیق باشد.
هم `.xlsx` هم `.csv` قابل قبول است.

## products-template.xlsx

| ستون | لازم؟ | توضیح |
|---|---|---|
| `کد` | نه | کد کالا (رشته). خالی هم می‌شود. |
| `نام کالا` | **بله** | |
| `واحد` | نه | مثل «عدد»، «خدمت»، «کیلوگرم». پیش‌فرض: عدد |
| `قیمت واحد (ریال)` | نه | عدد صحیح. پیش‌فرض ۰ |
| `معاف از مالیات` | نه | `بله` / `خیر` (یا `1` / `0`). پیش‌فرض: خیر |
| `موجودی اولیه` | نه | عدد. در **انبار «فاکتور رسمی»** به‌عنوان موجودی اولیه ثبت می‌شود. پیش‌فرض ۰ |

## قوانین بارگذاری
- ردیف‌های خالی نادیده گرفته می‌شوند.
- ردیفی که «نام» نداشته باشد رد می‌شود و در گزارش خطا می‌آید (بقیهٔ ردیف‌ها ثبت می‌شوند).
- بارگذاری = فقط **افزودن**. برای ویرایش/حذف از خود صفحه استفاده کن.
