# سامانه مدیریت فرآیندهای کسب‌وکار (BPM)

سامانه‌ای یکپارچه برای مدیریت کارها، گردش‌کارهای سازمانی (روتین)، حضور و غیاب، و پشتیبانی داخلی — نوشته‌شده با PHP خالص (بدون فریمورک) و رابط کاربری راست‌به‌چپ (فارسی).

## امکانات کلیدی

### مدیریت کارها
- تعریف کار مقطعی، دوره‌ای (روزانه/هفتگی/ماهانه) و پیوسته، با ارجاع و زنجیرهٔ تأیید
- چک‌لیست برای هر کار، با امکان ارجاع هر آیتم به یک کاربر یا واحد خاص
- درخواست تمدید موعد، رفع دوره‌های معوقه، و ثبت توضیحات تکمیل کار
- تاریخچهٔ کامل هر کار (ارجاع، تأیید/رد، تمدید موعد، تغییرات چک‌لیست) با جستجوی متنی در همهٔ فیلدها

### کارهای روتین (Workflow)
- طراحی الگوی روتین با چند مرحله، به‌صورت آبشاری (Cascade) یا موازی (Parallel)
- تعیین مسئول هر مرحله (کاربر مشخص، واحد سازمانی، یا ایجادکنندهٔ روتین)
- چک‌لیست اختصاصی برای هر مرحله؛ تا تیک‌نخوردنِ همهٔ آیتم‌ها، امکان تکمیل مرحله وجود ندارد
- پایش زندهٔ روتین‌های در حال اجرا و تأخیرها از صفحهٔ مانیتورینگ

### داشبورد و گزارش‌گیری
- داشبورد اختصاصی مدیر و کاربر با نمای ماهانه/هفتگی و آمار لحظه‌ای
- گزارش گلوگاه (Bottleneck)، گزارش روزانه، و نمای کلی کارهای سازمان برای سرپرست/مدیر
- حالت روشن و تاریک در سراسر برنامه

### حضور و غیاب (attendance_system)
- ثبت ورود/خروج، محاسبهٔ خودکار کسری کارکرد با احتساب تعطیلات رسمی
- درخواست مرخصی/تعیین وضعیت، و گزارش حقوق و دستمزد

### پشتیبانی (Ticketing)
- ثبت تیکت با اولویت، دسته‌بندی، و امکان پیوستن یک کار مرتبط برای مشاهدهٔ پشتیبانی
- رابط گفتگوی شبیه پیام‌رسان: پیام‌ها و پیوست‌ها بر اساس فرستنده (کاربر/پشتیبانی) تفکیک‌شده
- پیوست فایل با درگ‌اند‌دراپ یا چسباندن مستقیم تصویر از کلیپ‌بورد (Ctrl+V)

### مدیریت سازمانی و دسترسی
- پشتیبانی از چند سازمان و چند واحد فعالیت برای هر کاربر
- کنترل دسترسی مبتنی بر نقش (کاربر، مدیر، سرپرست، مدیر کل) برای هر بخش از سامانه
- مدیریت اعلانات، تعطیلات رسمی، و ارسال پیامک برای رویدادهای مهم

## تکنولوژی‌ها

- **بک‌اند:** PHP (بدون فریمورک)، PDO برای ارتباط با MySQL/MariaDB
- **فرانت‌اند:** جاوااسکریپت خالص، Bootstrap 5 (RTL)، AG Grid برای جدول‌های تعاملی
- **دیتابیس:** MySQL/MariaDB با سیستم مهاجرت (Migration) داخلی

## ساختار پروژه

```
htdocs/
├── api/                  # اندپوینت‌های API (تسک‌ها، تیکت‌ها، چک‌لیست، گردش‌کار و ...)
├── pages/                # صفحات اصلی برنامه (داشبورد، کارها، تیکت‌ها، تنظیمات و ...)
├── includes/             # کلاس‌ها و توابع مشترک (TaskManager، WorkflowManager، Auth و ...)
├── attendance_system/    # زیرسامانهٔ مستقلِ حضور و غیاب
├── modules/ticketing/    # دارایی‌های اختصاصی ماژول تیکتینگ
├── admin/                # پنل مدیریت کل
├── assets/               # فایل‌های استاتیک (CSS، JS، کتابخانه‌های CDN محلی)
├── migrations/           # مهاجرت‌های دیتابیس (هر فایل یک تغییرِ برگشت‌پذیر)
├── config/               # تنظیمات اتصال به دیتابیس (config.example.php را کپی کنید)
└── migrate.php           # ابزار خط‌فرمان/مرورگری اجرای مهاجرت‌ها
```

## پیش‌نیازها

- PHP نسخهٔ ۸ به بالا (پسوندهای `pdo_mysql`, `mbstring`, `fileinfo`)
- MySQL یا MariaDB
- یک وب‌سرور (Apache/XAMPP) — پروژه برای اجرا روی XAMPP تنظیم شده است

## نصب و راه‌اندازی

۱. پروژه را داخل پوشهٔ `htdocs` سرور محلی (مثلاً XAMPP) قرار دهید.

۲. فایل تنظیمات دیتابیس را از روی نمونه بسازید:

```bash
cp config/config.example.php config/config.php
```

سپس مقادیر را در `config/config.php` با اطلاعات دیتابیس خودتان جایگزین کنید:

```php
return [
    'db_host' => 'localhost',
    'db_name' => 'database_name',
    'db_user' => 'database_user',
    'db_pass' => 'database_password'
];
```

۳. یک دیتابیس خالی با کاراکتر‌ست `utf8mb4` بسازید و اطلاعاتش را در همان فایل تنظیمات وارد کنید.

۴. مهاجرت‌ها را اجرا کنید تا ساختار جداول ساخته شود (بخش بعد را ببینید).

۵. آدرس پروژه را در مرورگر باز کنید (مثلاً `http://localhost/htdocs/`).

## مهاجرت‌های دیتابیس

ساختار دیتابیس از طریق فایل‌های داخل پوشهٔ `migrations/` مدیریت می‌شود. هر مهاجرت شامل یک تابع `up` (اعمال تغییر) و `down` (بازگردانی) است.

```bash
php migrate.php status      # نمایش وضعیت مهاجرت‌ها (اجراشده/در انتظار)
php migrate.php up          # اجرای مهاجرت‌های در انتظار
php migrate.php up --dry    # پیش‌نمایش بدون اعمال تغییر واقعی
php migrate.php down        # بازگردانی آخرین مهاجرت
```

برای اجرا از طریق مرورگر (مثلاً روی هاست اشتراکی)، ابتدا مقدار `MIGRATE_SECRET` را در ابتدای فایل `migrate.php` به یک رشتهٔ تصادفی و طولانی تغییر دهید، سپس:

```
https://YOUR-DOMAIN/migrate.php?key=SECRET&action=status
```

## نقش‌ها و سطوح دسترسی

| نقش | دسترسی |
|---|---|
| کاربر عادی | مشاهده و انجام کارهای خودش، ارسال تیکت پشتیبانی |
| مدیر (Manager) | مدیریت زیرمجموعهٔ خودش، تعریف کار برای اعضای تیم |
| سرپرست (Supervisor) | نظارت بر کل سازمان، گزارش‌گیری، مدیریت روتین‌ها |
| مدیر کل | دسترسی کامل به تمام سازمان‌ها و تنظیمات سامانه |
